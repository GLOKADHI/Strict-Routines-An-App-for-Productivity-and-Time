Extension protection

Checking policy
Website access follows your desktop rules. Removal protection is a separate, optional Windows browser policy. An ordinary extension cannot prevent its own removal or lock your computer.
Managed protectionOptional

Request supported Windows browser policy to restrict access to the extension manager during discipline sessions.

Only applied and verified policy counts as protection. Administrator recovery remains available.

Standard installationDefault

Use normal browser extension management. This choice does not remove an already applied Windows policy.

Administrator recovery and technical details

Use StrictRoutines → Controls → Browser companions for administrator maintenance unlock. Then open this browser’s extension manager for normal management.

Windows browser policy can affect more than this one extension. Review its confirmed status before relying on removal protection.
